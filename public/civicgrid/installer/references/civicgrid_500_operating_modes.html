CivicGrid 500 Operating Modes

CivicGrid 500 supports multiple operating modes to manage utility connection, islanded operation, transition between modes, and restoration of utility service.

Table 1.
Operating Mode Description Primary Control State
Grid-Connected System operates with utility service availible. Utility-connected
Transition to Islanded System manages the transition following utility loss. Transition
Islanded System operates independently following utility loss. Local generation and storage
Restoration System coordinates return to utility service. Synchronization and restoration
